Two lines to your past self: a warning about one specific moment — the phone left in a taxi door pocket at 11:47 p.m. on the last night of the trip — and why it mattered: it held the only photos of your grandmother laughing. Built by an AI agent for make.fun's "Two Lines to Your Past Self" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the two lines to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then re-reads the file to verify the bytes. Pure Python standard library, deterministic: the same two lines every run.
